# Run the "build" stage of AnnoTALE.

A R wrapper around the
[AnnoTALE](https://www.ncbi.nlm.nih.gov/pubmed/26876161) 'AnnoTALE.jar
build' program. It usually takes is input from the file generated by the
[`run_annotale_predict`](https://scunnac.github.io/tantale/dev/reference/run_annotale_predict.md)
function.

## Usage

``` r
run_annotale_build(
  fasta_file,
  output_dir = getwd(),
  annotale_jar = system.file("tools", "AnnoTALEcli-1.5.jar", package = "tantale",
    mustWork = T)
)
```

## Arguments

- fasta_file:

  Path to a fasta file containing TALE sequences as returned by AnnoTALE
  (?) to be classified into groups.

- output_dir:

  Directory where output will be written (created if does not exist).

- annotale_jar:

  Path to the AnnoTALE jar file if you want to use another version than
  the one provided with tantale.

## Value

Returns invisibly the exit code of the shell call to Annotale (ie '0' if
successful).
