# Low-level constructor for a pairwise_distances object

Low-level constructor for a pairwise_distances object

## Usage

``` r
new_pairwise_distances(x, subclass = NULL, dom_code_namespace = NULL)
```

## Arguments

- x:

  A tibble.

- subclass:

  Optional entity subclass, `"tale_distances"` or `"domain_distances"`.

- dom_code_namespace:

  Optional scalar string, see
  [`tales_namespace`](https://scunnac.github.io/tantale/dev/reference/tales_namespace.md).

## Value

A `pairwise_distances` object.
